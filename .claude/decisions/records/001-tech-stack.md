# 001. 기술 스택

## 상태

- Accepted

## 맥락

세로 터치 키오스크에서 무인으로 구동되고 관람객 휴대폰에서도 열려야 합니다. 케이크 분석에 LLM을 호출하고, 공개 주소로 배포해야 합니다. 시안은 1080x1920 고정이며 모션 비중이 큽니다.

## 결정

Next.js 16(App Router) + React 19 + TypeScript, Tailwind CSS v3.4, motion, Zustand, Zod, Biome, Vitest, pnpm을 사용하고 Vercel에 배포합니다. 화면은 1080x1920 고정 스테이지를 뷰포트에 맞춰 배율 조정합니다.

## 근거

- LLM API 키를 숨길 서버가 필요합니다. route handler와 정적 화면을 한 저장소, 한 배포로 처리할 수 있습니다.
- 시안과 키오스크 패널(세로 1440x2560)의 비율이 9:16으로 같아 고정 스테이지가 키오스크를 꽉 채웁니다. 휴대폰에서는 같은 화면이 너비에 맞춰 축소됩니다.
- 화면 전환을 URL이 아닌 클라이언트 상태로 하므로 store 하나로 문답과 케이크 구성을 관리합니다.

## 대안

- Vite SPA: 서버가 없어 LLM 호출용 백엔드를 따로 두어야 합니다.
- 휴대폰용 반응형 레이아웃 별도 제작: 시안이 세로 고정 하나뿐이고 일정이 짧아 선택하지 않았습니다.
- TanStack Query: 서버 호출이 분석 한 번뿐이라 도입하지 않았습니다.

## 영향

- 화면은 `Stage` 안에서 시안 px 값으로 만듭니다 (`.claude/rules/project-constraints.md`).
- LLM 호출은 `.claude/rules/llm.md`를 따릅니다.
