# asset-cleanup

Figma MCP 는 **캔버스의 노드 그룹마다 파일을 하나씩** 내보냅니다.
같은 도형이 인스턴스 수만큼 복제되고, 장식 하나가 여러 조각으로 쪼개집니다.

## 읽을 문서

`.claude/rules/assets.md`

## Workflow

### 1단계: 중복 검사

```bash
cd public/img/<디렉터리>
for f in *.svg; do
  printf "%-20s %s\n" "$f" "$(sed -E '
    s/id="[^"]*"//g;
    s/url\(#[^)]*\)/url(#G)/g;
    s/[0-9]+\.[0-9]{2,}/N/g
  ' "$f" | md5 -q)"
done | sort -k2
```

세 가지를 모두 정규화해야 합니다. 하나라도 빠지면 중복을 놓칩니다.

| 정규화 | 왜 |
| --- | --- |
| `id="..."` | Figma 가 노드마다 다른 id 를 붙임 |
| `url(#...)` | 그라디언트 참조에 일련번호가 붙음 (`paint0_linear_0_7`) |
| 소수점 | 인스턴스마다 좌표가 0.01px 씩 다름 |

해시가 같으면 **파일 하나만 남기고 위치 배열로 반복**합니다.

### 2단계: 조각 병합

같은 영역을 덮는 장식이 여러 조각이면 하나의 SVG 로 합칩니다.
각 조각을 부모 기준 오프셋만큼 `translate` 하고, `id` 는 제거해 충돌을 막습니다.

### 3단계: 이미지가 필요한지 재검토

SVG 안의 색·크기가 **전부 기존 토큰이면 이미지를 쓰지 않고 div 로 그립니다.**
단계별 상태처럼 변형이 있는 요소는 특히 그렇습니다 — 이미지로 가면 상태 수만큼 파일이 늘어납니다.

### 4단계: 보고

```text
<디렉터리>  N개 X KB  →  M개 Y KB
  중복 제거: <파일명들> → <남긴 것>
  병합:     <파일명들> → <합친 것>
  div 전환: <파일명들>
```

## 하지 않는 것

- 원본 손실이 생기는 변환 (래스터화 등)
