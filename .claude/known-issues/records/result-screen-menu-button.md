# 결과 화면의 메뉴판 버튼과 시안에 없는 부분

## 무엇이 다른지

- 시안에는 하단 버튼이 3개입니다. 윗줄에 "메뉴판에서 고를래"(민트)와 "조금만 수정해 볼래!"(분홍)가 반씩 나란히 있고, 아랫줄에 "맘에 들어 ! 이대로 줘"가 있습니다. 구현에서는 "메뉴판에서 고를래"를 빼고, "조금만 수정해 볼래!"를 윗줄 전체 너비로 넓혔습니다.
- 시안의 카드에는 `2026.09.10`, `(001)`이 고정 글자로 그려져 있습니다. 구현에서는 오늘 날짜와 이 기기의 순번으로 바뀝니다.
- 시안에는 가장 큰 케이크 한 가지만 그려져 있습니다. 구현에서는 중간 크기를 0.9배, 미니를 0.8배로 그립니다. 결과 수정 화면의 크기 배율(0.8배, 0.6배)을 그대로 쓰면 카드가 비어 보여 차이를 줄였습니다.
- 카드가 뒤집히며 나타날 때 보이는 뒷면은 시안에 없습니다. 카드와 같은 회색 테두리에 빈 종이만 그렸습니다.

## 어디서 확인했는지

- Figma `1:91352` (결과 화면), `25:40680` (카드)
- `src/components/result/ResultScreen/ResultScreen.tsx`, `src/components/result/OrderCard/OrderCard.tsx`, `src/data/result.ts`

## 왜 지금 우리 코드에서 고치면 안 되는지

"메뉴판에서 고를래"가 가는 화면의 시안이 없습니다. 눌러도 반응이 없는 버튼을 무인 화면에 둘 수 없어 뺐습니다. 크기별 케이크와 카드 뒷면도 시안이 없어 임의로 정했습니다.

## 언제/누가 해결해야 하는지

디자이너가 메뉴판 화면을 정하면 그 화면 이슈에서 버튼을 다시 넣고, 윗줄 버튼 두 개를 시안의 반 너비로 되돌립니다. 크기별 케이크 배율과 카드 뒷면은 디자이너 확인 뒤 `src/data/result.ts`의 `CARD_CAKE_SIZES`와 `ResultScreen`의 뒷면을 고칩니다.
