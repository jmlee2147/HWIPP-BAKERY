# Known Issues

이 규칙은 우리가 지금 당장 고칠 수 없거나 우리 코드의 문제가 아닌, 외부 요인으로 발견된 이슈를 기록하는 방법을 정의합니다.

## 기록 대상

- 디자인 시스템/외부 패키지의 값이 Figma나 스펙과 다른 경우
- 서드파티 라이브러리 버그로 생긴 workaround
- 키오스크(webOS) 브라우저에서만 재현되는 동작 차이
- 시안 에셋이 규격과 달라 임의로 맞춘 경우
- 우선순위가 낮아 지금은 미루는 알려진 성능/품질 이슈

## 기록하지 않는 것

- 우리 코드로 바로 고칠 수 있는 버그 (그냥 고친다)
- 구조/라이브러리 선택 같은 결정 사항 (`.claude/rules/decisions.md` 참조)

## 파일 위치와 이름

이슈 문서는 `.claude/known-issues/records/`에 `short-title.md` 형식으로 둡니다.

## 작성 형식

새 이슈는 아래 템플릿을 복사해 작성합니다.

### 템플릿

```markdown
# 이슈 제목

## 무엇이 다른지

기대값과 실제 값을 비교해서 적습니다.

## 어디서 확인했는지

Figma 노드, 파일 경로, 실행한 명령 등 재현/확인 방법을 적습니다.

## 왜 지금 우리 코드에서 고치면 안 되는지

우리 코드의 문제가 아니거나, 지금 고치면 안 되는 이유를 적습니다.

## 언제/누가 해결해야 하는지

해결 주체(외부 패키지 관리자, API 팀 등)와 대략적인 시점을 적습니다.
```
