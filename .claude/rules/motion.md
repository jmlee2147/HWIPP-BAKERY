# 모션 규칙

이 프로젝트는 모션 비중이 큽니다. 다만 키오스크는 TV급 칩셋이므로 가벼운 기법을 먼저 씁니다.

## 도구 선택

| 상황 | 도구 |
| --- | --- |
| 화면 전환, 등장/퇴장, 제스처, 레이아웃 전환 | `motion` (`motion/react`) |
| 무한 반복 장식(둥둥 떠다니기, 일렁이는 그라데이션, 회전) | CSS `@keyframes` |
| 2프레임 캐릭터 반복 | CSS `steps()` 또는 이미지 2장 교차 |
| 카드 뒤집기 | CSS 3D transform (`rotateY`, `backface-visibility`, `perspective`) |
| 컨페티 | 2D canvas 파티클. 도입 시 의존성 확인을 받습니다 |
| 효과음 | Web Audio. 첫 터치 이후에만 재생됩니다 |

three.js 등 WebGL은 쓰지 않습니다 (`.claude/decisions/records/003-no-threejs.md`).

## 성능

- `transform`과 `opacity`만 애니메이션합니다. `width`, `height`, `top`, `left`, `box-shadow`, `filter`를 프레임마다 바꾸지 않습니다.
- 큰 `blur`, `backdrop-filter`, 전면 `mix-blend-mode`를 움직이는 요소에 쓰지 않습니다.
- 동시에 움직이는 레이어 수를 줄입니다. 화면 밖 화면의 반복 애니메이션은 unmount하거나 멈춥니다.
- `will-change`는 실제로 끊기는 요소에만 붙입니다.
- 모션 성능은 개발 PC가 아니라 키오스크 실기기에서 판단합니다.

## 시안의 모션 요구

시안 메모에 적힌 요구입니다. 구현 전에 해당 Figma 노드의 메모를 다시 확인합니다.

| 구간 | 요구 |
| --- | --- |
| 오프닝 | 케이크가 둥둥 떠다님, 빈 배경에 케이크가 하나씩 생겨남, 문이 효과음과 함께 열림, 캐릭터 2프레임 반복 |
| 관계 | 진행 바 그라데이션이 일렁임, 카드 클릭 시 뒤집히며 변경, 선택하기 버튼으로만 다음 진행 |
| 스타일 | 폴더 5개 중 하나를 고르면 해당 창이 뜸 |
| 파티 | 캘린더 그리드: 축소해 그리드가 보였다가 다른 칸으로 이동하며 확대, 선택 시 컨페티 |
| 맛 | 위아래 스크롤, 특정 위치에 걸리거나 선택되면 색상 변경 |
| 로딩 | 케이크 조각이 하나씩 사라지며 회전, 끝날 때까지 무한 반복, 캐릭터도 함께 움직임 |

## 우선순위

플로우가 끝까지 이어지는 것이 모션보다 먼저입니다. 화면을 정적인 상태로 먼저 완성하고 모션을 얹습니다.
