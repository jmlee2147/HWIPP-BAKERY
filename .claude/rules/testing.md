# 테스트 규칙

## 테스트 위치

- 단위 테스트와 컴포넌트 테스트는 대상 파일 옆에 둡니다.
- 유틸리티 테스트는 `.test.ts`, React 컴포넌트 테스트는 `.test.tsx`를 사용합니다.

## 도구

- 단위/컴포넌트 테스트는 Vitest를 사용합니다.
- React 동작 테스트는 Testing Library를 사용합니다.
- 컴포넌트 테스트 환경은 happy-dom입니다.

## 테스트 대상

- 회귀 가능성이 있는 동작을 테스트합니다.
- 체험 단계 전환(store), 문답 답변에서 케이크 구성으로 가는 규칙 기반 매핑, LLM 응답 검증과 실패 시 대체 경로를 우선합니다.
- 케이크 부품 조합 규칙(형태별 장식 선택, 겹침 순서)을 테스트합니다.

## 피할 것

- 모션의 중간 프레임이나 CSS class 자체를 테스트하지 않습니다.
- snapshot-only 테스트만 두지 않습니다.
- 구현 세부사항을 그대로 복제하는 테스트를 피합니다.
- 실제 LLM을 호출하는 테스트를 두지 않습니다.
