# AI 파이프라인 규칙

## AI에게 전부 맡기지 않습니다

| 산출물 | 생성 주체 | 이유 |
| --- | --- | --- |
| 매핑 컬러 | **결정적 테이블** (`lib/mapping`) | 디자인 팔레트를 벗어나면 안 됩니다 |
| 추천 디자인 | **결정적 테이블** | 준비된 케이크 이미지 에셋 중에서만 선택 가능합니다 |
| 매핑된 맛 | 테이블 + AI 보정 | 조합 규칙은 고정, 선택 근거만 AI |
| 관계 한줄평 | **AI** | 창작이 필요한 유일한 영역 |
| AI 레터링 추천 | **AI** | 케이크 위 문구 |

AI는 **자유 텍스트 2종 + 테이블 선택지 중 하나를 고르는 역할**입니다.
렌더 불가능한 값이 나올 수 없는 구조로 만듭니다.

## 호출 형태

`app/api/analyze/route.ts` — 서버 전용(API 키 노출 없음).

- 모델: `claude-opus-5`
- 구조화 출력: `client.messages.parse()` + `zodOutputFormat(RecipeSchema)` → `parsed_output` 타입 보장
- **컬러·디자인·맛 필드는 Zod enum**으로 정의 → 에셋에 없는 값이 원천 차단됩니다
- `max_tokens: 4000` (짧은 응답). 지연이 중요하므로 `output_config.effort: "low"`
- 시스템 프롬프트는 `lib/claude/prompt.ts`에 상수로 두고 `cache_control: ephemeral`로 캐시합니다

## 폴백 — 전시가 멈추지 않는 것이 최우선

API 실패·타임아웃·스키마 불일치 시 **결정적 매핑 테이블 + 사전 작성 한줄평 풀**로 폴백합니다.
관람객은 이 사실을 모릅니다.

- 폴백은 예외가 아니라 **설계된 분기**입니다. 에러 UI를 만들지 않습니다.
- **무음 폴백에는 반드시 짝이 있어야 합니다.** 관람객은 몰라도 개발자는 알아야 합니다 —
  폴백이 반복되면 네트워크나 API 문제라는 신호입니다. 서버 로그에 기록을 남깁니다.
- 클라이언트 대시보드가 아니라 **서버 로그**로 추적합니다 (`.claude/rules/operations.md`).

## 공개 API 보호 — 없이 배포하지 않습니다

**문제**: 앱이 공개 URL에 배포되고 QR로 도메인이 관람객 휴대폰에 노출됩니다.
즉 **누구나 `POST /api/analyze`를 반복 호출할 수 있고, 그대로 Claude API 비용이 됩니다.**

| 방어 | 구현 |
| --- | --- |
| **Rate limit** | IP당 분당 N회. Vercel KV로 처리. 키오스크 트래픽은 세션당 1회뿐이라 넉넉히 잡아도 막힙니다 |
| **Origin 체크** | `Origin`/`Referer`가 자기 도메인이 아니면 거부. 브라우저 밖 호출을 걸러냅니다 |
| **키오스크 토큰** | 키오스크만 아는 값을 헤더로. 빌드 타임 주입, 공유 페이지에는 노출되지 않습니다 |
| **일일 상한** | 하루 총 호출 수 상한. 초과 시 폴백으로 전환 — **비용이 새는 것보다 폴백이 낫습니다** |
| **`max_tokens` 상한** | 4000으로 제한. 폭주 시 피해를 축소합니다 |

완벽한 차단은 불가능합니다(클라이언트에 있는 건 다 털립니다). 목표는 **비용 폭탄 방지**이고,
**일일 상한이 마지막 방어선**입니다. preview 환경에도 적용합니다.

공유 페이지(`/r/[resultId]`)는 읽기 전용이고 AI를 호출하지 않으므로 공개해도 됩니다.

## 경계에서 런타임 검증

TypeScript 타입은 컴파일 타임에만 존재합니다. **밖에서 들어오는 값은 전부 런타임 검증합니다.**

| 경계 | 검증 |
| --- | --- |
| AI 응답 | Zod. 컬러·디자인·맛은 enum |
| KV에서 읽은 결과 레코드 | Zod. 스키마를 바꾼 뒤 옛 레코드가 남아 있을 수 있습니다 |
| `/api/*` 요청 바디 | Zod |
| 환경변수 | 부팅 시 1회 검증. **누락이면 즉시 기동 실패** — 런타임에 `undefined`로 새는 것보다 낫습니다 |

## 데이터

- 결과 레코드 TTL **30일** (전시 종료 후 자동 정리)
- 답변은 **선택지 코드값만** 저장합니다. 자유 텍스트·개인 식별 정보를 저장하지 않습니다.
- 로그에도 개인정보를 넣지 않습니다.
